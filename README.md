# 로스팅 생산일지 전산화 도구

손으로 쓴 로스팅 생산일지(스캔 PDF)를 엑셀로 옮기고, 제품별 L값·Agtron 측정값과 적정 규격 범위를 웹 대시보드로 보는 도구예요.

> 회사 실제 데이터(일지 기록, 엑셀)는 이 저장소에 없어요. 각자 PC의 `데이터` 폴더와 `로스팅일지.xlsx`에만 있어요.

## 구성

| 파일 | 하는 일 |
|---|---|
| `엑셀만들기.py` | `데이터` 폴더의 기록(.csv)을 모아 `로스팅일지.xlsx`를 만듦 (전체기록 + 날짜별 시트, 특이값 표시, 읽기 어려운 값은 노란색) |
| `대시보드.html` | PC에서 여는 대시보드. 엑셀을 골라 넣으면 제품별 측정값, 적정 규격 범위, 특이값 검토 목록을 보여 줌 |
| `대시보드_웹.html` | 같은 대시보드의 웹 게시용 버전 |
| `로스팅일지_기획서.md` | 기획서 (기준 문서) |
| `사용방법.md` | 매일 쓰는 순서 |

## 계산 규칙

| 값 | 적정 범위 | 특이값 |
|---|---|---|
| L값 | 기준 L값 ±0.3 (기준이 범위면 양 끝에서 ±0.3) | 적정 범위 밖 |
| Agtron | 특이값을 뺀 평균 ±5 | 그 제품 전체 측정값 중간값 ±5 밖 |

특이값은 평균·최대·최소 계산에서 빠지고, 엑셀 `특이사항` 칸에 남아요.

## 기록 파일 형식 (`데이터/*.csv`, UTF-8)

```
PDF,쪽,일자,배전기명,배치,제품명,제품코드,기준L,L,Agtron,확인필요
1,1,2026-01-05,PROBAT,1,예시 제품,00000000,18.0,18.1,40.0,
```

- `기준L`은 숫자 또는 범위(`19.5~20.0`)
- `확인필요`: 읽기 어려운 칸 이름을 `|`로 이어 적음 (`제품명|L|Agtron`) → 엑셀에서 노란색

## 실행

```powershell
py -m pip install openpyxl
py 엑셀만들기.py
```

대시보드는 `대시보드.html`을 브라우저로 열고 **엑셀 파일 선택**에서 `로스팅일지.xlsx`를 고르면 돼요. (엑셀은 브라우저 안에서만 읽고 어디에도 보내지 않아요.)
